# B21 Scanner Agent

Локальный мост между браузером и сканером Windows. Открывает родное окно
сканирования Windows (WIA), полученное изображение отдаёт веб-приложению B21,
которое загружает его на сервер (CoA при приёмке, скан-копии актов и т.д.).

## Зачем

Браузер не может напрямую управлять планшетным/протяжным сканером (запрет
веб-стандартов). Агент устанавливается на каждый АРМ оператора и слушает
`http://127.0.0.1:8765`. Веб-приложение опрашивает агент: если он запущен —
показывает кнопку «Сканировать», иначе остаётся загрузка файла.

## Требования

- Windows 10/11
- Сканер с установленным WIA-драйвером (стандарт для большинства МФУ/сканеров)
- Python 3.10+ (только для запуска из исходника; для .exe не нужен)

## Установка и запуск (из исходника)

```bat
cd scanner-agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python agent.py
```

Или просто двойной клик по `run-agent.bat` (если Python и зависимости
установлены глобально).

Агент выведет: `B21 Scanner Agent v0.1.0 → http://127.0.0.1:8765`

## Автозапуск при входе в Windows (рекомендуется)

Чтобы агент не запускать вручную каждый раз — настройте автостарт один раз:

```bat
install-autostart.bat
```

Скрипт создаёт ярлык в папке «Автозагрузка» текущего пользователя, который
запускает агент **без окна консоли** (через `pythonw`/`pyw`) при каждом
входе в систему. Отключить автозапуск:

```bat
uninstall-autostart.bat
```

После `install-autostart.bat` агент стартует при следующем логине. Чтобы
поднять его сразу, без перезагрузки, скрипт печатает готовую команду
`start "" pythonw ...agent.py`.

## Сборка автономного .exe (без Python на АРМ)

На машине с Python:

```bat
pip install pyinstaller
pyinstaller --onefile --noconsole --name b21-scanner-agent agent.py
```

Готовый `dist\b21-scanner-agent.exe` копируется на АРМ. Варианты автозапуска:
- ярлык на `.exe` в папке `shell:startup` (как делает `install-autostart.bat`,
  но с .exe вместо pythonw), либо
- регистрация как службы Windows через NSSM (`nssm install B21ScannerAgent
  "C:\path\b21-scanner-agent.exe"`).

Для прод-развёртывания .exe предпочтительнее: Python на АРМ не требуется,
обновление = замена одного файла.

## API (для справки)

| Метод | Путь | Назначение |
|-------|------|-----------|
| GET | `/status` | проверка, что агент жив (версия) |
| GET | `/scanners` | список WIA-сканеров |
| POST | `/scan` | открыть окно сканирования, вернуть JPEG (base64) |

Ответ `/scan`:
```json
{ "filename": "scan.jpg", "mime_type": "image/jpeg", "data_base64": "...", "size": 12345 }
```

## Как это работает в B21

1. На странице приёмки (или загрузки скан-копии) фронт делает `GET /status`.
2. Если агент ответил — рядом с «Загрузить файл» появляется «Сканировать».
3. По нажатию фронт вызывает `POST /scan` → агент открывает окно WIA →
   оператор сканирует → агент возвращает JPEG.
4. Фронт превращает base64 в файл и загружает на сервер B21 (тот же
   endpoint, что и обычная загрузка) — с sha256 и записью в аудит.

## Несколько станций / доступ через Tailscale

Агент **локальный, по одному на каждый ПК**. `127.0.0.1` для браузера всегда
означает «эта же машина», поэтому:

- у каждого оператора, который сканирует, должен быть **свой сканер** и
  **свой запущенный агент** на его ПК;
- один сканер «расшарить» по сети (Tailscale) на всех нельзя — каждый
  сканирует своим устройством через свой локальный агент.

Если B21 открывается по Tailscale-адресу (`http://100.x.x.x:5173`), а агент
на `127.0.0.1` — Chrome по умолчанию может заблокировать запрос политикой
**Private Network Access**. Агент уже отдаёт заголовок
`Access-Control-Allow-Private-Network: true`, что снимает блокировку. Если
всё равно блокирует — проверьте, что у пользователя:
1. запущен агент (`http://127.0.0.1:8765/status` отвечает в его браузере);
2. установлен драйвер сканера (в Диспетчере устройств есть «Устройства
   обработки изображений»).

## Безопасность

- Слушает только `127.0.0.1` — недоступен по сети.
- Ничего не хранит: изображение живёт в памяти/временном файле до ответа.
- CORS разрешён для локального приложения; для прод-домена добавьте его в
  `allow_origins` в `agent.py`.

## Прод по HTTPS

Если B21 открывается по `https://`, вызов `http://127.0.0.1:8765` может быть
заблокирован как mixed-content в части браузеров. Решения:
- запускать агент c локальным TLS-сертификатом (`uvicorn --ssl-*`), либо
- использовать `https://127.0.0.1:8765` с самоподписанным сертификатом,
  доверенным на АРМ.
Для пилота по `http://127.0.0.1:5173` ограничения нет.
